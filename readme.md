Gota De Nieve 🍦

Bienvenido al repositorio de Gota De Nieve, una página web diseñada para representar una heladería con una imagen fresca, moderna y atractiva.

Esta carpeta contiene todos los archivos y recursos necesarios para el desarrollo y funcionamiento del sitio web, incluyendo el código fuente, imágenes, hojas de estilo, scripts y demás elementos relacionados con el proyecto.

El objetivo de esta página es ofrecer a los usuarios una experiencia agradable al conocer los productos, promociones, información de la heladería y sus datos de contacto, manteniendo un diseño intuitivo, responsivo y de fácil navegación.

Contenido de la carpeta:

- Archivos HTML de la estructura del sitio.
- Hojas de estilo (CSS).
- Imágenes, logotipos e íconos.
- Recursos multimedia y documentos del proyecto.

Proyecto: Página web de la heladería Gota De Nieve.
